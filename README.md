# RFPS_Lab2 - Лабораторна робота № 2

Дисципліна: **«Розробник фронтенду програмних систем»**

Варіант № 6 - тема **«Стилізація елементу інтерфейсу засобами CSS»**

Обраний усталений стиль веб-дизайну: **мінімалізм**.

## Що зроблено

Стилізовано три сторінки, розмічені в Лабораторній роботі № 1:

- **зовнішня таблиця стилів** - `css/style.css` (підключена тегом `<link>`);
- **внутрішні таблиці стилів** - блоки `<style>` у розділі `<head>` кожної сторінки
  (стилі, унікальні для конкретної сторінки: позиціонування шапки, рамки карток,
  flex-розкладка форми тощо).

### Головна сторінка (index.html)
- блок «назва корпорації та логотип» - `position: absolute`, `top: 0`, `z-index: 50`;
- блок «мета + список завдань» - зовнішні відступи `margin: 46px 0`, внутрішні `padding: 0`;
- таблиця засновників - при наведенні `transform: scale(1.05)` (масштаб +5 %);
- адреса й телефони - тінь від літер з'являється через 2 с (`transition-delay: 2s`);
- після опису мети - емодзі-директор через псевдоелемент `::after`;
- найбільший текстовий блок має власну смугу прокручування (`overflow-y: auto`).

### Сторінка «Напрями діяльності» (directions.html)
- шапка `position: fixed` (фіксована зверху);
- картки напрямів - у рамці темно-помаранчевого кольору: права межа суцільна
  середньої товщини, решта - подвійні;
- текст «зв'язок із державними органами» - менша вага/висота гліфів та похилий;
- при фокусуванні на фото насиченість кольорів зростає до 200 % (`filter: saturate(200%)`);
- посилання в момент кліку (`:active`) - темно-зелений колір;
- розкладка карток - модуль **Grid**, плюс анімація появи (`@keyframes`).

### Сторінка «Зворотний зв'язок» (feedback.html)
- форма стилізована модулем **Flex**: `flex-flow`, `justify-content`, `align-items`,
  `align-content`; для елементів - `order`, `flex-grow`, `flex-shrink`, `flex-basis`,
  `align-self`.
